# **App Name**: TireShop Local

## Core Features:

- Tire Search: Allow users to search for tires based on criteria such as vehicle type, tire size, and brand. This involves extracting data from the tireflow.ezytire.com script.
- Local Dealer Integration: Integrate with local tire dealers to display tire availability, pricing, and installation options.
- Free Wheel Alignment Promo Display: Show promotion banner.
- Informational Content: Explain steps involved to help the users.

## Style Guidelines:

- Primary color: Dark Blue (#0A79C8) to reflect trust and stability of auto services.
- Background color: Light Gray (#F9FAFB) to provide a neutral backdrop.
- Accent color: Lighter Blue (#41B3FF) to highlight calls to action and interactive elements.
- Headline font: 'Plus Jakarta Sans' sans-serif for headlines to provide a modern, bold look.
- Body font: 'Inter' sans-serif for body text to provide clear, readable text.
- Use simple, outlined icons related to tires, wheels, and auto services. Icons should use the primary color (#0A79C8).
- Implement a clean, grid-based layout with clear sections for easy navigation. Ensure the tire search tool is prominently displayed.
- Add subtle transition effects and hover states on buttons and interactive elements. Avoid overly flashy animations to maintain a professional appearance.
